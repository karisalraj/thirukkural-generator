# 📖 Thirukkural Generator

A beautiful Tamil Thirukkural Generator website built using HTML, CSS, and JavaScript.

## 🚀 Features

* Random Thirukkural Generator
* Tamil Meaning Display
* Responsive Design
* Mobile Friendly
* Glassmorphism UI
* GitHub Hosted

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Thirukkural API
